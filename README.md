# Jayden Boyd - Portfolio Revamp

A modern, highly interactive personal portfolio website built to showcase projects, technical skills, and professional experience.

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics**: [Three.js](https://threejs.org/) (Powers the immersive Hero section)

## 📁 Project Structure

The Next.js application is located in the `portfolio-site/` directory.

Key components of the site (`portfolio-site/components/`) include:
- **Hero**: An interactive, 3D-powered introduction using Three.js (loaded client-side).
- **Projects**: A showcase of recent work and applications.
- **Stack**: A breakdown of technical skills and tools.
- **Experience**: Professional background and timeline.
- **Contact**: Ways to reach out and connect.

## 🛠️ Getting Started

First, navigate to the application directory:

```bash
cd portfolio-site
```

Install dependencies (if you haven't already):

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. The application will auto-update as you edit the source files.

## 🚀 Deployment

This project is optimized for deployment on [Vercel](https://vercel.com/), the creators of Next.js. You can effortlessly deploy the `portfolio-site` directory by importing it as a new Vercel project.
